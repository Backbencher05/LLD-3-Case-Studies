======================================================================
OUR SOFTWARE DISCOVERY FRAMEWORK (SDF)
======================================================================

Every software system should be discovered using the same five questions.

1. Who owns the responsibility?

→ Class

2. What work must it perform?

→ Method

3. What knowledge must it remember?

→ Attribute

4. Who must it collaborate with over time?

→ Relationship

5. Who owns its lifecycle?

→ Object Creation

This framework must be reused in every future case study.
